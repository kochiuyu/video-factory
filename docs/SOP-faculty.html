Six steps

  1. Pick one module for the week, not every short. Students watch the module; shorts are backup.
  2. Assign one treatment from treatments.csv. File names look like ECON-M01__en__cap-burn__1p00x.mp4 — lesson, speech, captions on/off, speed. Do not rename.
  3. Upload the MP4 to Blackboard / Moodle / KEEP. Attach the matching .srt if the player can turn captions on. Soft captions = Year 2 / SEN option.
  4. Release the student quiz HTML or CSV after the video. Mark with the key. Scores are out of 100.
  5. Do not mix speeds in one cell. A student in the 1.5× arm only sees the 1p50x file. Log the cell_id from the CSV next to the student id.
  6. If a file is missing, send the operator the module id. Faculty do not rebuild videos. Operators use the console: select the module → tick languages → Build. Experiment pack is optional.
